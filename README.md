# Donut Case
A pill case, but in the shape of a DONUT!

# Blurb
This project was made with OnShape in about 2 hours. You may feel free to use any of the provided STL files

# Assembly

Its a little intuitive, but you can stack up the pieces to spin. 

You get BASE on the bottom, then put the BOX on the BASE. SPIN goes on top of everything, it is the cover that opens and closes the hole for a pill. LID goes on the very top. You might see how it works by now. You can glue LID to BASE if you'd like some more stability.
